文章中の漢字に、できるだけ多く振り仮名を付けるための辞書です。Scenario Snip の振り仮名辞書に読み込んで使えます。

| ファイル | 内容 |
| --- | --- |
| `ruby-pack.json` | 188,714 語と、規則の語 491 件 |
| `compiled/ruby-pack.json` | ライブラリの C#・Python 版用に変換したもの |

一般の語・熟語・活用形・難読語・固有名詞・数字と助数詞（3日、10分 など）を収録しています。Scenario Snip に最初から入っている約 1 万語も、同じ読みで含めています。

## Scenario Snip で使う

1. 「振り仮名」ダイアログを開きます。
2. 「インポート」ボタンで `ruby-pack.json` を選ぶか、ダイアログへドラッグ＆ドロップします。
3. 「閲覧モードで確認」で、振り仮名が付いたことを確かめます。

- Scenario Snip **v2.6.1 以降**で使えます。規則の語（後述）が働くのは **v2.7 以降**です。
- 読み込みには数秒かかります。読み込んだあとの操作の速さには、ほとんど影響しません。
- パックはブラウザに保存されません。使うたびに読み込んでください。
- 書き出した HTML に入るのは、本文で使っている語だけです。HTML の大きさはほとんど増えません。
- パックの語を編集・無効化・削除した内容は HTML に記録されます。パックを読み込んだあとにその HTML を開くと、編集した内容が戻ります。

## 振り仮名が付かない箇所

文字列が一致した箇所に、自動で振り仮名を付けます。次のような箇所には付きません。

- 読みが文脈で変わる語。例: 行った（いった／おこなった）、上（うえ／じょう）、昨夜（さくや／ゆうべ）
- 位取りで書いた漢数字。例: 六〇〇、一九
- 数字の付かない「分頃」「本目」など。前の数によって「ふん／ぷん」などが変わるためです（「5分頃」なら付きます）
- 熟語の一部になっている漢字 1 文字。例: 「鳥類」の「鳥」、「見出す」の「出す」
- 名前や造語の途中・後ろにある漢字 1 文字

「今日」は、単独では付けません。「今日が」「今日こそ」など一部の形では「きょう」と付きます。「今日は」には付けません（あいさつの「こんにちは」と区別できないため）。

間違った振り仮名が付いたときは、振り仮名ダイアログでその語を編集・無効化・削除してください。

## 正確さ

| | 漢字のうち振り仮名が付く割合 | 付いた振り仮名の正確さ |
| --- | --- | --- |
| Scenario Snip の既定の語だけ | 約 1〜7% | — |
| 既定の語＋このパック | 約 87%（シナリオ文は約 89%） | 約 99% |

正確さは、青空文庫・Wikipedia などの本文で振り仮名が付いた箇所から無作為に 3,982 か所を選び、AI が文脈を見て判定した結果です。誤りは 34〜43 か所でした（正確さ 98.9〜99.15%）。標本の数が限られるため、±1.5 ポイント程度の幅があります。

残っている誤りは、次のように文脈を見ないと避けられないものです。

- 語の境目をまたいで当たる（「先頭文字」に「頭文字（かしらもじ）」が当たる など）
- 送り仮名を省いた古い書き方（決って）
- 熟字訓の一部（真っ蒼の「蒼」）
- 人名・地名

## 作り方

語の選定と読みの見直しは、AI（大規模言語モデル）が例文を見て行いました。人が 1 語ずつ確かめたものではありません。

1. **候補を集める**: 青空文庫と Wikipedia の本文（約 9 億バイト）を形態素解析（UniDic）し、20 回以上現れて、そのうち 97% 以上が同じ読みになる語を集めました。旧版のパック（UniDic・SudachiDict・JMdict/JMnedict の読みが一致する約 5.8 万語）も引き継いでいます。
2. **規則で作る**: 数字と助数詞（3日＝みっか、2人＝ふたり、10分の「分」＝ぷん など）と漢数字の日付は、形態素解析の読みが当てにならないため、規則で作りました。「1日」（ついたち／いちにち）は収録していません。
3. **全件を見直す**: すべての語について、本文で実際に振り仮名が付いた箇所の例文を AI が見て判定し、読みの誤りを直し、読みが割れる語を取り除きました。例: 川＝がわ → かわ、日本＝にっぽん → にほん（正式名が「にっぽん」の語は除く）、下手人＝へたひと → げしゅにん。
4. **漢字の連なりを 1 語として足す**: 本文に 5 回以上現れ、まだ 1 語として振り仮名が付かない漢字の連なり（本人・物語・赤鉛筆 など）のうち、読みが 1 つに決まる 5,062 語を足しました。
5. **当たり方を確かめる**: 別の本文（約 1.5 億バイト）に辞書全体を当て、語の境目をまたいだり、読みが食い違ったりすることが多い語（15% 以上）を取り除きました。

### 規則の語

`者+直前漢字`＝しゃ、`時+直前ひらがな`＝とき のように、直前の文字の種類（漢字・ひらがな・カタカナ・英数字）で読みが決まる漢字 1 文字です（491 件）。たとえば「スキー場」の「場」には、`場+直前カタカナ` で「じょう」と付きます。直前の文字の種類ごとに読みを数え、20 回以上現れて 97% 以上が同じ読みになる組だけを収録しています。

### 「よくある読み」パックの廃止

読みが複数ある語を集めた別パック「よくある読み」（12,256 語）は、2026-10-03 に廃止しました。メインへ移せるか試したところ、正確さが約 94% にとどまり、基準の 99% に届かなかったためです。

### 収録の決まり

- 同じ文字列に 2 つの読みを持たせていません。読みが割れると、どちらも付かなくなるためです。
- 送り仮名には振り仮名を付けません。例: 送り火 → 「送」に「おく」、「火」に「び」
