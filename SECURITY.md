# セキュリティ / Security

## 脆弱性の報告

脆弱性を見つけたときは、Issue ではなく、GitHub の [非公開の報告](https://github.com/wyichojime/furigana-pack/security/advisories/new)（Security タブの「Report a vulnerability」）から知らせてください。内容を確かめて、修正してから公開します。

## Reporting a vulnerability

Please do not open a public issue. Report it privately via [GitHub's private vulnerability reporting](https://github.com/wyichojime/furigana-pack/security/advisories/new) (Security tab → "Report a vulnerability").

## 対象 / Scope

最新の `main` だけを対象にします。ライブラリは実行時の依存パッケージを持たず、外部と通信しません。

Only the latest `main` is supported. The library has no runtime dependencies and makes no network requests.
